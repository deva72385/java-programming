There are n people standing in a line 
labeled from 1 to n. The first person in the 
line is holding a pillow initially. Every second, 
the person holding the pillow passes it to the
 next person standing in the line. Once the pillow 
reaches the end of the line, the direction changes, and people continue 
passing the pillow in the opposite direction.


class Solution {
    public int passThePillow(int n, int time) {
        int direction=time/(n-1);
        int i=time%(n-1);
        if(direction%2==0){
            return 1+i;
        }
        return n-i;
             }
        
    
}
